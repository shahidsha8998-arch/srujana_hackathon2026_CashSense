# Srujana Tech Fest 2026 Submission

##  Project Overview
This project was developed during the 48-Hour **Srujana Tech Fest 2026 Hackathon** at Chanakya University. The application delivers an automated software solution tailored to solve complex problem requirements within the **Finance / Legal Services** domain.

The platform provides a streamlined user workflow, clear presentation of complex domain information, and AI-assisted processing designed to deliver reliable insights to users.

---

##  Tech Stack & Development Workflow

* **Frontend & Design:** Built with **Antigravity** for rapid interface prototyping and deployment.
* **AI Assistance & Prompt Engineering:** Formulated using **Gemini** & **Grok** for step-by-step logic implementation, detailed instructions, and workflow optimizations.
* **Documentation & Submission:** Structured according to the Srujana Tech Fest 2026 rules and guidelines.

---

##  Key Features & Highlights

1. **User Interface:** Interactive and easy-to-navigate dashboard for managing data and workflows.
2. **AI Integration:** Assisted by domain prompts to ensure structured data handling and domain accuracy.
3. **Robust Workflow:** Step-by-step guidance designed for reliability, clarity, and ease of use.
4. **Transparency & Disclaimers:** Clear boundaries established for automated recommendations, keeping in line with hackathon guidelines.
